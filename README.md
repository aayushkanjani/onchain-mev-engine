# On-Chain Arbitrage & MEV Engine

A research-oriented implementation of an on-chain trading system.

The project will progressively evolve from:

1. AMM simulation
2. Arbitrage detection
3. Historical blockchain analysis
4. Real-time blockchain ingestion
5. MEV opportunity detection
6. Transaction simulation
7. Execution infrastructure

## Current Phase

### Phase 1 — AMM Research & Simulation

We are implementing a constant-product AMM and studying:

- Liquidity pools
- Constant-product invariant
- Swap mechanics
- Trading fees
- Price impact
- Slippage
- Arbitrage

## Long-Term Architecture

Python will initially be used for research and simulation.

Performance-critical components will eventually be implemented in Rust.
